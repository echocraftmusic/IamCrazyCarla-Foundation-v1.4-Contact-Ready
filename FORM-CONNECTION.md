# Contact Form Connection

The website contact form is connected to FormSubmit and routes inquiries to:

`aahfro10@gmail.com`

## One-time activation

1. Open the website through VS Code Live Server or the published domain.
2. Submit one test inquiry.
3. FormSubmit will send an activation email to Carla.
4. Carla must open that message and click the activation/confirmation link.
5. Submit a second test inquiry and confirm it reaches her inbox.

No password or email login is stored in the website. The phone number has been removed from the page and structured website data.

After the domain is live, an optional custom thank-you page can be connected with FormSubmit’s `_next` field.
